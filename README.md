# Markdown Heading Tool

## 项目用途

Markdown Heading Tool 是一个纯前端 Markdown 标题层级修改工具。用户可以粘贴 Markdown 文本，将符合规则的 ATX 标题统一升级或降级一级，再复制转换结果。

项目主要在电脑上使用，同时兼容手机。电脑宽屏可采用输入区和输出区左右排列，手机窄屏采用上下排列。本项目不是手机优先项目，但手机端需要正常操作。

## 第一版目标

V1 目标是完成一个简单、可靠、无需安装的网页工具，只处理符合固定规则的 ATX 标题，并避免误改其他内容。

## 第一版支持的功能

- 粘贴 Markdown 文本；
- 将 ATX 标题统一升级一级或降级一级；
- 一级标题继续升级时保持一级；
- 六级标题继续降级时保持六级；
- 普通正文、列表、引用和行内出现的 `#` 保持不变；
- 反引号代码围栏和波浪号代码围栏中的内容保持不变；
- 复制转换结果；
- 清空输入和输出；
- 电脑端主要使用，手机端可以正常操作；
- 电脑宽屏可左右排列输入区和输出区，手机窄屏采用上下排列。

### V1 标题识别规则

- 行必须直接以 1 到 6 个 `#` 开头；
- `#` 后必须紧接一个普通半角空格；
- 不支持行首缩进；
- 不支持用制表符代替普通空格；
- `# ` 这种带普通空格的空标题可以识别；
- 单独的 `#` 暂不识别；
- 七个或更多 `#` 不识别；
- 不支持 Setext 标题。

### V1 代码围栏规则

- 支持三个或更多反引号；
- 支持三个或更多波浪号；
- 开始围栏和结束围栏前允许 0 到 3 个普通空格；
- 4 个或更多行首空格暂不作为代码围栏识别；
- 围栏开始行可以在围栏标记后包含语言名称等信息；
- 开始和结束围栏必须使用相同字符；
- 结束围栏长度必须大于或等于开始围栏；
- 结束围栏后允许普通空格或 Tab；
- 结束围栏后如果存在其他文字，则不视为有效的结束围栏；
- 未关闭的代码块持续到文本末尾；
- 代码围栏开始行、结束行和内部内容全部保持原样。

## 第一版暂不实现的功能

- Setext 标题；
- 文件上传；
- 多文件批量处理；
- Markdown 实时预览；
- 云端保存；
- 用户账户；
- 浏览器扩展；
- 桌面安装程序；
- 框架、Node.js、数据库、后端服务和外部依赖。

## 当前项目状态

项目目前处于第一版的需求整理和测试设计阶段。V1 的功能范围、固定规则和测试用例已经记录，页面与转换功能尚未开始实现。

## 技术范围说明

- 使用普通 HTML、CSS 和 JavaScript；
- 纯前端运行，不需要服务器；
- 不使用框架、Node.js、数据库、后端服务或外部依赖；
- 采用响应式设计，但不是手机优先项目；
- 浏览器可能将输入文本中的换行统一规范化为 LF；
- V1 保留文本行结构、空行数量和末尾换行状态；
- V1 不承诺区分或保留输入原本的 LF 与 CRLF 类型；
- 项目文本文件使用 UTF-8 编码。
