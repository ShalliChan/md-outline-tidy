# Markdown Heading Tool

## 项目用途

Markdown Heading Tool 是一个用于快速调整 Markdown 标题层级的纯前端工具。

## 当前已实现功能

- 支持 Markdown ATX 标题（`# 标题`形式）的一级升级和降级；
- 支持 1～6 级标题调整；
- 一级标题继续升级时保持一级；
- 六级标题继续降级时保持六级；
- 代码围栏中的内容不会被修改；
- 正文、列表、引用和普通 `#` 符号不会被误处理；
- 支持复制转换结果；
- 支持清空输入、输出和状态提示。

## 使用方法

1. 将 Markdown 文本粘贴到输入框；
2. 点击“升级一级”或“降级一级”按钮；
3. 在输出框查看转换结果；
4. 使用复制按钮复制结果；
5. 使用清空按钮重新开始。

## 支持规则

- 支持 ATX 标题格式；
- 支持反引号和波浪号代码围栏保护；
- 仅处理标题层级，不解析完整 Markdown 语法。

## 技术说明

- 使用 HTML、CSS 和 JavaScript 实现；
- 纯前端运行；
- 无需安装依赖；
- 无需服务器；
- 浏览器打开即可使用。

## 当前限制

- 一级标题不会继续升级；
- 六级标题不会继续降级；
- 不支持 Setext 标题；
- 不支持批量文件处理；
- 不保存用户输入内容。
